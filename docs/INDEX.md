# 도파밈 프로젝트 문서

이 폴더에는 도파밈 프로젝트의 모든 상세 문서가 포함되어 있습니다.

---

## 📚 문서 목록

### 1. [종합 문서 (DOCUMENTATION.md)](./DOCUMENTATION.md)
**프로젝트 전체를 아우르는 종합 문서**

#### 포함 내용
- 프로젝트 개요 및 비즈니스 가치
- 기술 아키텍처 및 스택
- 데이터베이스 설계 (ERD, 스키마)
- 핵심 기능 구현 상세
- UI/UX 디자인 시스템
- 인증 및 보안
- 배포 및 운영
- 개발 가이드
- 향후 로드맵 (2025~2027)

#### 대상
- 전체 팀원
- 신규 개발자 온보딩
- 투자자 및 파트너

---

### 2. [화면 기획서 (WIREFRAME.md)](./WIREFRAME.md)
**전체 페이지별 상세 Text Wireframe**

#### 포함 내용
- 전체 페이지 레이아웃 (ASCII 다이어그램)
- 공개 페이지 (랜딩, 로그인, 회원가입, 소개, 약관)
- 인증 필요 페이지 (예측 시장, 예측 상세, 내 활동, 순위표)
- 관리자 페이지 (마켓 생성, 결과 확정)
- 공통 컴포넌트 (헤더, 푸터)
- 반응형 디자인 가이드
- 인터랙션 가이드
- 상태 표시 가이드

#### 대상
- 디자이너
- 프론트엔드 개발자
- UI/UX 기획자

---

### 3. [비즈니스 기획서 (dopameme_plan.md)](./dopameme_plan.md)
**서비스 기획 및 비즈니스 전략**

#### 포함 내용
- 서비스 개요 및 정의
- 서비스 목표 및 비전
- 타겟 고객 분석
- 핵심 기능 (포인트 시스템, 예측 게임, 커뮤니티)
- 차별화 전략
- 비즈니스 모델 (수익화 방안)
- MVP 구축 범위

#### 대상
- 경영진
- 기획자
- 마케팅 팀

---

### 4. [개발 계획서 (dopameme_dev.md)](./dopameme_dev.md)
**MVP 개발 로드맵 및 기술 스택**

#### 포함 내용
- 프로젝트 개요
- 기술 스택 선정 이유
- 아키텍처 및 라우팅 구조
- Supabase 데이터베이스 스키마 (초안)
- 단계별 개발 로드맵 (6주 계획)
- MVP 이후 고려 사항

#### 대상
- 개발팀
- CTO
- 기술 컨설턴트

## 📖 문서 읽기 가이드

### 신규 개발자 온보딩

1. **[종합 문서](./DOCUMENTATION.md)** 읽기 (1~3장)
   - 프로젝트 개요 이해
   - 비즈니스 기획 파악
   - 기술 아키텍처 학습

2. **[개발 가이드](./DOCUMENTATION.md#9-개발-가이드)** 따라하기
   - 로컬 환경 설정
   - 개발 워크플로우 익히기
   - 코드 스타일 가이드 숙지

3. **[화면 기획서](./WIREFRAME.md)** 참고
   - 주요 페이지 레이아웃 파악
   - UI 컴포넌트 이해

### 기능 개발 시

1. **[종합 문서 - 핵심 기능 구현](./DOCUMENTATION.md#5-핵심-기능-구현)** 참고
   - 관련 기능의 상세 구현 내용 확인

2. **[화면 기획서](./WIREFRAME.md)** 참고
   - 해당 페이지의 레이아웃 확인
   - 인터랙션 및 상태 표시 가이드 참고

3. **[데이터베이스 설계](./DOCUMENTATION.md#4-데이터베이스-설계)** 참고
   - 관련 테이블 스키마 확인
   - 주요 쿼리 패턴 활용

### 기획 및 전략 수립 시

1. **[비즈니스 기획서](./dopameme_plan.md)** 검토
   - 서비스 목표 및 비전 재확인
   - 타겟 고객 및 차별화 전략 파악

2. **[종합 문서 - 향후 로드맵](./DOCUMENTATION.md#10-향후-로드맵)** 참고
   - Phase별 계획 확인
   - 우선순위 결정
