   - "예측 참여하기" 버튼
   - 주의사항: 중복 베팅 불가, 취소/변경 불가

   - 선택한 옵션
   - 베팅액
   - 베팅 시점
   - 상태 (진행 중 / 승리 / 패배)
   - 현재 확률 (진행 중인 경우)
   - 예상 또는 실제 지급액
   - 순수익 및 수익률 (확정된 경우)
