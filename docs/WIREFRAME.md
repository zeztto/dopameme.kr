2. **마켓 헤더**
   - 카테고리 배지 + 관리자/상태 아이콘
   - 마켓 제목
   - 마켓 설명
   - 생성자, 생성일, 마감일 (또는 확정일)

   - 결과 (확정된 경우)

   - 총 베팅액
   - 총 참여자
   - 내 베팅액 (참여한 경우)

4. **옵션 현황**
   - 2개 옵션: 좌우 비율 막대
   - 3개 이상: 개별 진행 막대
   - 각 옵션: 제목, 확률, 베팅액, 진행 막대
   - 확정된 경우: 승리 옵션에 ✅ 표시

5. **가격 차트**
   - 옵션별 확률 변화 SVG 차트
   - 최근 예측 참여/부분 청산 스냅샷 기준
   - 진행 중 마켓은 주기적 새로고침

6. **예측 참여 폼** (진행 중 + 미참여)
   - 라디오 버튼: 옵션 선택
   - 베팅 금액 입력 (100 ~ 10,000 DPMM)
   - 내 잔액 표시
   - AMM 평균가 및 예상 확률 변화 표시
   - 예상 지급액 계산 (실시간)
   - "예측 참여하기" 버튼
   - 주의사항: 중복 베팅 불가, 옵션 변경 불가, 마감 전 부분 청산/전체 포지션 판매 가능

7. **내 예측 내역** (참여한 경우)
   - 선택한 옵션
   - 베팅액
   - 부분 청산 폼 (active, hidden=false, 마감 전)
   - 포지션 판매 등록/취소 폼 (active, hidden=false, 마감 전)
   - 베팅 시점
   - 상태 (진행 중 / 승리 / 패배)
   - 현재 확률 (진행 중인 경우)
   - 예상 또는 실제 지급액
   - 순수익 및 수익률 (확정된 경우)

### 3.4 이상 거래 탐지 (/admin/stats/anomalies)

**URL**: `/admin/stats/anomalies`
**접근 권한**: 관리자만
**목적**: 예측, DPMM ledger, 출금 요청, 포지션 거래 신호를 기반으로 수동 검토가 필요한 이상 거래 후보 확인

#### 주요 요소

1. **탐지 요약**
   - 전체 alert 수
   - critical/high/medium severity count
   - 관찰 사용자 수
   - 최근 24시간 stake
   - 열린 출금 요청 합계

2. **탐지 모델 정보**
   - model version
   - 최근 window
   - baseline days
   - 생성 시각

3. **운영 기준 패널**
   - read-only 탐지임을 명시
   - 자동 계정 정지/잔액 변경/출금 거절 없음
   - score는 수동 검토 우선순위

4. **최상위 신호**
   - 최고 risk score alert
   - severity, type, 사용자, 주요 metric
   - score bar

5. **Alert 리스트**
   - prediction velocity
   - market concentration
   - ledger velocity
   - withdrawal pressure
   - position transfer velocity
   - evidence grid
   - 회원 상세 및 근거 확인 link

6. **빈 상태**
   - 임계값을 넘은 신호가 없을 때 안내
   - 회원 관리/마켓 통계 link
